Improves OpenCode agent delegation according to the same philosophy as codex-subagent-delegation, tying different subagents to specific models.

Installation:

- Copy `config-v1.json` to `~/.config/opencode/opencode.json`
- Copy `config-v2.jsonc` to `~/.config/opencode/opencode.jsonc`
- Copy `opencode-agents.md` to `~/.config/opencode/AGENTS.md`
