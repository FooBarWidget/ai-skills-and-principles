## Translation guidelines

Translate terminology by contextual meaning, using established target-language equivalents consistently and avoiding awkward or unclear literal renderings. Retain source-language terms only when requested, conventional for the audience, or necessary for accuracy; put any necessary explanations of unfamiliar retained terms in a separate translator's note.

Before responding, silently:

* Read the translation independently as a target-language editor, checking naturalness, clarity, terminology, and unnecessary source-language remnants.
* Compare it with the original for mistranslations, omissions, additions, and changes in meaning or tone.
* Fix identified issues and recheck affected passages.

Return the translation, with only necessary translator's notes unless otherwise requested. Flag unresolved material ambiguities rather than guessing.
